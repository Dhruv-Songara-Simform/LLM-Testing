📊 DEEPEVAL WORKFLOW
═══════════════════════════════════════════════════════════════════════════

1. Enter API Endpoint
   Example: http://localhost:3000/api/chat

2. (Optional) Add System Prompt
   Example: "You are a helpful assistant"

3. Add Test Prompts
   Use defaults or add your own custom prompts

4. Click "Run DeepEval"

5. View Results:
   • Conversation Tab → See all Q&A pairs
   • Analysis Tab → Detailed metrics (response times, counts)
   • Artifacts Tab → Download evaluation results


📈 METRICS YOU'LL SEE
═══════════════════════════════════════════════════════════════════════════

After running DeepEval, you'll get:

✓ Total Messages       Number of Q&A exchanges
✓ Avg Response Time    Average time to respond (milliseconds)
✓ Min/Max Time         Fastest and slowest responses
✓ Number of Prompts    How many test prompts were used
✓ Evaluation Date      When the evaluation ran
✓ API Endpoint         Which endpoint was tested


💾 STORED ARTIFACTS

❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Port 3000 already in use?
   → Use a different port: PORT=3001 npm start

API connection error?
   → Check .env file has valid credentials
   → Verify internet connection
   → Ensure DeepSeek API is accessible

Evaluation fails?
   → Double-check the API endpoint URL
   → Ensure endpoint is running
   → Check browser console for errors
